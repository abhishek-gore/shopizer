## 🚀 Quick Start

```bash
cd shopizer
mvn clean install
cd sm-shop
mvn spring-boot:run
```

Access Swagger API docs: http://localhost:8080/swagger-ui.html

## 🔑 Key Technologies

- **Java 11** + **Spring Boot 2.5.12**
- **Hibernate** + **Spring Data JPA**
- **MySQL** / PostgreSQL / H2
- **Spring Security** + **JWT**
- **OpenSearch** for product search
- **Drools** for business rules
